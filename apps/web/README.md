# Shkuna — Web

אפליקיית [Next.js](https://nextjs.org) בתוך המונורפו. לתיאור הפרויקט, פקודות משותפות והתקנה — ראו [README בשורש](../../README.md).

## פיתוח מקומי

מהשורש:

```bash
pnpm exec turbo dev --filter=web
```

או מתוך התיקייה:

```bash
pnpm dev
```

השרת ברירת המחדל: [http://localhost:3000](http://localhost:3000).
